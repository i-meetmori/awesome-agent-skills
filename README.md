# Awesome Agent Skills

A curated list of good AI agent skills I come across.

## Skills

| Repo | Description |
| --- | --- |
| [janestreet/agent_skills](https://github.com/janestreet/agent_skills) | Jane Street's collection of skills for AI agents and chatbots. Currently includes `socratic-tutor`, which turns an LLM into a strict personal tutor using the Socratic method: a diagnostic, a skill map with levels 0-5, one question at a time, spaced review, and a final assessment. Works with any agent that supports the `SKILL.md` format, or paste the skill body into a chatbot. |
